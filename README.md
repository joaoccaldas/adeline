# Adeline - Multiplayer Card Game

A real-time multiplayer card game built with React and Socket.IO. Create a room, share the code, and play with friends.

## Features
- Real-time multiplayer over WebSockets
- Mobile-first responsive UI
- Reconnection support
- React Context API state management

## Local development
```bash
npm install
npm run dev
```

## Deployment
Deploy to a Node.js hosting provider with WebSocket support.

## Status
Complete and open source for family or group game nights.
